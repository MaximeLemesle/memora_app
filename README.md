# Memora – Application Flutter de création d’albums de vacances

## 🪧 À propos

Memora est une application Flutter qui vous permet de créer, personnaliser et imprimer vos albums de vacances. Depuis la couverture jusqu’aux pages intérieures, organisez vos souvenirs et préparez un beau livre photo à partager ou à offrir.

## 🚀 Installation

### 📂 Télécharger le projet

1. Clonez le dépôt :
   ```bash
   git clone https://github.com/votre-utilisateur/memora_app.git
   ```
2. Entrez dans le dossier du projet :
   ```bash
   cd memora_app
   ```

### 🔧 Vérification des dépendances

Assurez-vous d’avoir Flutter 3.19.x et Dart 3.3.x installés avec la commande :

```bash
flutter doctor
```

Si des warnings apparaissent, suivez les conseils pour installer les SDK manquants.

### 🚀 Lancer l’application

Dans le terminal exécutez:

```bash
flutter pub get
flutter run
```

Votre simulateur ou appareil connecté démarrera automatiquement l’application.

## 🧰 Fonctionnalités

### 🎨 Création d’un nouvel album

Choix du titre, de la couverture (avec upload d’image) et dates de voyage.
Ajout d’une description et gestion des membres (amis, famille…).

### 📄 Génération automatique de la première page

Création d’une page de garde personnalisée reprenant les infos de l’album.

### 🖼️ Ajout de pages intérieures

Plusieurs templates de pages prédéfinis:
Texte : grand paragraphe + image.
Image : galerie / mosaïque de photos.
Mosaïque : grille d’images.

### 📦 Impression & Export (à venir)

Impression de votre album en haute résolution.
